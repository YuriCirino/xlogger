# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

xLogger only writes to a `Print` stream you provide, so security issues are unlikely.
If you still find one (for example, a buffer overflow), **do not open a public issue**.
Report it privately through GitHub's
[private vulnerability reporting](https://github.com/YuriCirino/xlogger/security/advisories/new),
or contact [@YuriCirino](https://github.com/YuriCirino) directly.

You should receive an answer within a week. Ordinary bugs go in the
[issue tracker](https://github.com/YuriCirino/xlogger/issues).
